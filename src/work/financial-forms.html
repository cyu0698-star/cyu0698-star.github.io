01 问题

传统财务的「人工地狱」

正式设计前，先把功课做足：50+ 家企业调研对接、5 家核心客户深度访谈。痛点很快浮出水面：

  • 无 ERP、人力成本高：中小企业普遍缺少大型 ERP，财务每天要把送货单、对账单、报价单手动录入 Excel 20–50 次。
  • 对错误近乎零容忍：一个数字出错会层层放大，一个笔误可能意味着数小时的人工对账。
  • 技术断层：传统 OCR 输出无逻辑的非结构化文本；通用聊天机器人每轮都会忘记格式，无法形成稳定工作流。
  • 真实诉求：「把这份乱糟糟的 PDF，放进我们公司正在用的那个 Excel 模板里。」——没有现成工具能做到。

02 AI 原生个人工作流

我怎么交付这个项目

我放弃了传统「纯手工」设计流水线，用 AI 协作工作流成倍放大研发与设计效率：

  • 竞品调研与内容生成（ChatGPT / Claude Design）：用大模型拆解传统 OCR 与通用聊天机器人的体验断层，快速生成贴合财务合规场景的真实化数据与文案。
  • 原型生成（Figma Make）：自然语言与组件库耦合，产出多个交互布局方案，大幅缩短 PoC 周期。
  • 代码交付与设计评审（Cursor / Gemini）：以设计师身份直接驱动前端（Next.js）与 Agent 后端（FastAPI）代码，用 Gemini 做代码评审与设计还原度审计。

03 Agent 策略

为什么这是一个强 AI Agent 产品

为满足财务团队「100% 准确」的要求，我把一次性输入输出的 AI 工具重塑为 Agentic Workflow：多层理解、置信度评分与自动回退，回应复杂业务场景下 Agent 设计的四个核心要素。

1 双轨输入

新手「⚡ 智能转换」，专家「自定义模板」

新手路径：无需选模板，Agent 自动识别文件类型并推荐流程。专家路径：上传企业表单截图，定义高精度的空间解析规则；一张截图 30 秒内配好模板。

2 可见的推理

动态能力标签 + 三层可读性

Agent 运行的 30 秒里拒绝冰冷的转圈，用「正在分析表头… 正在提取金额… 正在匹配供应商…」可视化推理；模板确认时用绿色质量卡（置信度）、表格网格预览、按类型分组的字段标签让用户一眼读懂。

3 Human-in-the-loop

Edit Form 检查点：导出前把控制权交还给人

提取完成后进入按语义分区的三段式编辑页（公司信息、明细数据、汇总），支持手动修正与增删行。这「一秒摩擦」消除了对 AI 自动导出错误数据的恐惧。

04 把 AI 局限变成设计机会

Agent 调优策略

业务痛点 / AI 缺陷对策原则
LLM 幻觉：字段缺失时编造地址、电话Temperature 0 + 带自检清单的提示词，强制「不确定就留空」宁空勿猜：诚实的空白远比精致的谎言更能赢得财务用户的长期信任
单点故障：依赖单一 LLM 供应商可插拔后端：一个环境变量在 Claude / OpenAI / 本地 PaddleOCR 间切换安全与业务连续性是企业级 Agent 产品的底线
安全与隐私：敏感财务数据所有 AI 调用经由后端代理端点，前端禁止直连 API安全是默认属性，不是营销噱头

05 交付即调试

一次「静默成功」

2026 年 7 月我抓到自己埋的雷：智能转换成功后界面毫无反馈——Excel 下载了，用户却以为失败了。当天补上成功面板。教训：AI 产品里，不说话的成功和失败长得一模一样。

06 下一步

Diff 对比与批量模式

  • Diff 对比视图：同一文件二次解析时，高亮 Agent 提取结果的变化，支持字段级一键接受 / 拒绝。
  • 多文档批量模式：并发调度多个 Agent 实例批量处理单据，聚合输出为一张结构化总表。
