01 What users want

Drop it in and it’s organized — no sorting first

The product is Flowtica’s “Help-You-Organize” on Web and Mac (mobile has a separate three-channel version). Text / images in → AI organizes them into a Memo or To-do; audio → advanced transcription and summary, producing a Meeting.

Five goals for this release: a channel menu pops up next to the entry (Quick Input / Upload audio); text and images can coexist in Quick Input, with multi-select for images; “Open with Flowtica” in Finder brings files straight into the matching dialog, skipping the channel menu; text and images are organized by AI, while audio goes straight to transcription and summary; across closing, failure, insufficient quota and asynchronous generation, one submission never creates duplicate tasks, and users can always get their results back.

Organize as offers Auto / To-do / Memo, with Auto as the default: AI decides between Memo and To-do, and one input can produce one Memo, one or more To-dos, or both.

Among comparable products, mymind, Mem and Notion all work as “drop it into one entry”; Gemini Notebook has a unified entry but asks for the source type first; Plaud, iFlytek, Limitless and DingTalk Tingji are recording-only. Not one of these 8 stops mid-organizing to ask the user.

02 Problem & context

Three things to solve before launch

The Mac app already had a “help me process” entry, but no consistent organizing queue for text, images, audio and desktop files; mobile has three channels (text only / add photos / upload audio), which Mac narrowed to two.

  1. One entry for many kinds of input: text and images in the same box, audio on its own.
  2. Every state and exception covered: drafts, drag and drop, insufficient quota, failure, no network, processing, multiple images.
  3. Web and Mac built from one set of designs and kept consistent.

Hard rules in the PRD (the design has to catch every one)

  • 5000-character limit; the counter appears from 4000; once the limit is reached, the microphone is disabled.
  • Up to 10 images; going over shows a prompt but clears nothing; a successful send clears the draft, a failed one keeps the original text and the category choice.
  • Task bar (colored bar) + stacking for multiple tasks + Retry in the failed state; a category +1 hint; drafts save automatically.
  • Dragging files onto the main window or the Dock icon shows a dark full-window hover state, “Release to organize with Flowtica”; dragging audio into Quick Input first asks whether to switch channels.
  • Bringing files in from Finder triggers a draft-conflict dialog (Discard / Save draft); a cancelled voice input can be undone within 10 seconds; transcription with no response for 20 seconds counts as failed, with unlimited retries; voice credits and AI interactions are two separate quotas.

04 Three judgment calls

Why this, why not the alternatives, and what it costs

01 Entry

A unified input box, not channel-first

Users want to “drop it in”, not “sort it first”; mymind / Mem / Notion never ask. The PRD split channels in this release for technical reasons: audio runs through the transcription pipeline and needs fast upload and fast structuring.

How it would work (a design-side judgment): one drop zone on the front end + detection by file type; on the back end, a routing layer sends files to the existing per-type pipelines (audio transcription, image recognition, text extraction) — no pipeline rebuild. The real risk is upload progress and timeouts for large video / PPT files, which has nothing to do with whether the entry is unified; progress and failure recovery need their own design.

Cost: when the type is detected wrongly, there has to be a “switch channel” way out; audio entering the unified box still has to go through the privacy notice and quota check.

Personal retrospective proposalLive: channel menu + audio branch

02 Image area

Option E, overturning grid A, which four AI reviewers unanimously recommended

E = a single horizontally scrolling row + fade + arrows; the thumbnail strip doesn’t make the dialog taller (dialog height 380 → 304), and the input area stays visible. A’s grid pushes the text area down.

Cost: from 6 images on, thumbnails switch to the 72 / 8 size; I did a round of corrections myself on 5 details, such as where the × sits and dropping the arrows’ backing plate.

Result: on both platforms, the live thumbnail strip matches E.

03 Subtraction

No motion, none of the three “visual upgrades”

The hover pop-up animation on images: I proposed dropping it myself in the review meeting; all three “visual upgrades” were rejected; after the review cut download / edit inside Quick Input, I didn’t bring them back.

Why: this release’s value is “drop it in and it’s organized”, not decoration; every extra animation means aligning both platforms one more time.

Cost: plainer screens; the visual points have to be won back through consistent details (see 06).

Three baselines for error recovery

  • One submission never creates duplicate tasks.
  • A failure keeps the original text and choices; retries are unlimited.
  • Users can always get their results back from the task bar or the list.

Audio branch

Audio doesn’t go into Quick Input; it has its own channel: choose upload in the channel menu → system file picker → validation (longer than 5 hours / unreadable file / single-audio limit) → privacy notice → quota check → colored “transcribing” bar.

08 Personal retrospective · redesign

If I set the direction, this is what I’d change

Note: what follows is my personal post-launch retrospective, not what was delivered at the time; for the live product, see 07.
  1. Move the entry toward a unified input box (see 04, call 01).
  2. Collapse Organize as during capture, defaulting to Auto; let users change the category on the result page, and add “Reorganize”.
  3. Limits: the counter appears only at 4000 and switches to a warning color when full; the button greys out at 10 images; when pasted text is too long, say how much was cut, or turn it into an attachment.
  4. Voice: a glow that follows the volume, new copy after about 5 seconds of silence, automatic spacing; AI rewrites visible and reversible.
  5. Results skip the task bar and land on a timeline that switches cards automatically by time; badges accumulate and only reset when the category is opened.
  6. Traceable results: Content gets an AI label plus a title + time line, and every conclusion links back to the original words / image.
  7. Multiple images reuse “Todo gallery · large image + thumbnail strip”: one viewer component + Original / Enhanced highlighting + left / right arrows.
  8. Save automatically on close, fixing only the overwrite on reopen and the cursor; unify quota into one dialog: remaining quota + reset date + an Upgrade primary button; full-window overlay “Release to organize”.

Expanding into: the same feature in the app (the three-channel mobile version), Apple Watch multi-device sync (a concept, not a shipped feature), structuring as soon as you finish speaking, automatic transcription and summaries (the meeting flow).

09 How I’d do it again

Turn the three baselines into a state table first, then draw the first screen

“Drop it in → it’s organized → you can find it again” becomes a state table first; the entry never makes users sort first; every “looks nicer” addition waits until after launch.
